# UniHealth — site

Site oficial do UniHealth em https://unihealthapp.com.br (GitHub Pages).

- `build.mjs` gera as páginas. A Política de Privacidade e os Termos vêm do texto do app
  (`../unihealth/src/data/legal.json`). Depois de mudar algo: `node build.mjs`, commit e push.
- `CNAME` aponta o domínio próprio.
